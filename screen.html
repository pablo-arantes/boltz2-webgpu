Folds locally on WebGPU. The affinity module is a second checkpoint and a second forward pass; its two outputs come from heads trained on different data and are not interchangeable.

Built on LocalFold (Beerware, Sergey Ovchinnikov) — this page and the Boltz-2 affinity path are additions to it. Structure and affinity weights are boltz-community/boltz-2, MIT; the affinity method is reverse-engineered from jwohlwend/boltz (MIT), whose code is read rather than vendored. The viewer is py2Dmol. Alignment searches, when you ask for one, run against the public ColabFold MMseqs2 server — please cite Mirdita et al., Nature Methods 19, 679–682 (2022). No AlphaFold 3 parameters are used or redistributed by this page.
